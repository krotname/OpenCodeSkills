# OpenCodeSkills

Два агента могут успешно закончить работу и оставить изменения, которые трудно объединить. Здесь каждая задача получает отдельный Git worktree, число параллельных запусков ограничено, а координатор проверяет код завершения и настоящий файл с результатом.

[English](README.md) · [Пример двух задач](examples/parallel-demo.mjs) · [Настройка MCP](mcp/opencode-subagents/README.md)

## Состав

| Компонент | Польза |
| --- | --- |
| `opencode-parallel-agents` | Разделение задач, сбор результатов и объединение проверенных изменений |
| `mcp/opencode-subagents` | `spawn`, `wait`, `result`, `cancel`; до четырёх запусков; отдельные ветки |
| `powershell-invocation` | Аргументы и Unicode при работе через PowerShell, SSH и WinRM |
| `gh-fix-ci` | Поиск причины упавшей проверки GitHub Actions перед исправлением |

## Установка

Клонируйте репозиторий и скопируйте три папки навыков вместе с их содержимым в `.opencode/skills` вашего проекта. Для глобальной установки используйте `~/.config/opencode/skills`. Команды для Linux и PowerShell приведены в [английском README](README.md#install-the-skills).

Навыку параллельной работы нужен отдельный MCP-сервер. Остальные навыки работают независимо. Нужны Node.js 22+, Git и OpenCode с авторизованным провайдером, который поддерживает модель сервера. Для `gh-fix-ci` нужны Python 3.10+ и авторизованный `gh`.

## Проверка и настоящий параллельный запуск

```sh
node scripts/verify.mjs
node examples/parallel-demo.mjs
```

Первая команда проверяет протокол и жизненный цикл через управляемый тестовый CLI без обращения к модели. Вторая запускает две реальные задачи OpenCode до ожидания их результатов: одна создаёт текстовый файл, другая — JSON в другом worktree. Команда выводит идентификаторы запусков, каталоги и результат проверки файлов. Демо расходует два небольших обращения к модели.

Модель и вариант закреплены в сервере и не меняются параметрами запроса. Worktree создаётся от сохранённого HEAD: незакоммиченные изменения не копируются, ветки не сливаются автоматически. В негитовом каталоге разрешён один активный писатель. Ошибка лимита провайдера завершает затронутую задачу и сохраняется в её результате.

## Обновления

Это выбранное публичное ядро приватного источника. Экспорт допускает только перечисленные файлы и проверяет их до публикации; приватная история не переносится. Независимая правка публичного файла останавливает следующий экспорт до согласования с источником.
